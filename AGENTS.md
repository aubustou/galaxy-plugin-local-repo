# AGENTS.md

Guidance for AI coding agents working on this repository.

## Project overview

`galaxy-plugin-local-repo` is a GOG Galaxy 2.0 integration plugin that exposes
DRM-free game installers stored on local disk as games in the Galaxy library.

- The plugin scans every subfolder of `LOCAL_REPO_DIR` for a `game.json` file
  (one game per subfolder).
- Each game is identified by a UUID stored in its `game.json`; if missing, the
  plugin generates one and writes it back.
- "Installing" a game runs the installer executable referenced in `game.json`.
- Aggregated state is persisted in `LOCAL_REPO_DIR/local_repo.json`.

## Repository layout

| Path | Purpose |
| --- | --- |
| `galaxy_local_repo/local_repo.py` | **The plugin itself** — the only first-party module inside the plugin folder. |
| `galaxy_local_repo/manifest.json` | Galaxy plugin manifest (name, platform, GUID, version, entry script). |
| `galaxy_local_repo/{galaxy,aiohttp,attr,async_timeout,certifi,chardet,idna,multidict,yarl,bin}/` | **Vendored third-party dependencies** (Galaxy API SDK and its deps), including `cp37-win32` binary extensions. |
| `game_template.json` | Template for a game's `game.json`. |
| `mover.py` | Standalone helper script: moves `Download <name>.*` files from the repo root into per-game subfolders and creates their `game.json`. |

## Key rules

- **Do not modify vendored packages** under `galaxy_local_repo/` (everything
  except `local_repo.py` and `manifest.json`). They are copied as-is so the
  folder can be dropped into Galaxy's plugins directory. If a dependency must be
  upgraded, replace the whole package and mention it explicitly.
- **Target runtime is Python 3.7, 32-bit Windows** (the Python embedded in GOG
  Galaxy; see the `cp37-win32.pyd` extensions). Do not use syntax or stdlib
  features newer than 3.7 (no walrus operator, no `list[str]` generics, no
  `match`, etc.).
- The plugin runs on Windows: paths such as `LOCAL_REPO_DIR` are Windows paths.
  Use `pathlib` for path handling.
- Keep `version` in `manifest.json` and the version passed to `Plugin.__init__`
  in `local_repo.py` in sync when bumping the version.
- Do not change the plugin `guid` in `manifest.json`: Galaxy uses it to identify
  the integration.

## `game.json` format

```json
{
    "title": "Your DRM-free game",
    "installer_file": "setup.exe",
    "compatible_os": ["windows"],
    "uuid": "<auto-generated if absent>",
    "image_files": []
}
```

- `title` (required), `installer_file` (relative to the game folder),
  `compatible_os` (`windows`, `mac`, `linux`), `uuid` and `image_files`
  (optional).
- Keep `game_template.json`, `mover.py` and `LocalRepoPlugin.get_games` consistent
  if this format changes, and update the README.

## Plugin architecture notes

- `LocalRepoPlugin` subclasses `galaxy.api.plugin.Plugin` and implements the
  Galaxy JSON-RPC hooks (`authenticate`, `get_owned_games`, `install_game`,
  `get_local_games`, `get_os_compatibility`, ...).
- `tick()` is called periodically by Galaxy; it schedules
  `check_for_new_games` and `check_for_installed`, each guarded by an
  `asyncio.Event` to avoid concurrent runs and throttled with a 5 s sleep.
  Any early `return` in these coroutines must clear the event, otherwise the
  task never runs again.
- `LocalRepoGame` extends the SDK `Game` dataclass; `GameEncoder` serialises it
  to `local_repo.json`. Add new fields to both when extending game metadata.
- Use `logging.debug(...)` for diagnostics (Galaxy collects plugin logs).

## Development & testing

- There is no test suite, CI, or packaging configuration.
- Quick sanity check after editing:
  `python -m py_compile galaxy_local_repo/local_repo.py mover.py`
- Unit tests, if added, can use the SDK mocks in
  `galaxy_local_repo/galaxy/unittest/mock.py`; run them with
  `PYTHONPATH=galaxy_local_repo`. Note that the vendored `aiohttp`/`yarl`/`multidict`
  rely on Windows binaries, so tests on Linux may require installing those
  packages from PyPI instead.
- Real end-to-end testing requires copying `galaxy_local_repo/` into GOG
  Galaxy's plugins folder on Windows and restarting Galaxy.

## Conventions

- Code style: Black-compatible formatting, type hints, f-strings.
- Commit messages: short imperative English sentences (e.g. "Add lock on asyncio
  tasks").
- Documentation (README, comments) is written in English.
